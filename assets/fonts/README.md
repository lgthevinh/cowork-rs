# Emoji Font Assets

Place an emoji-capable font here so the app can load emoji glyphs explicitly.

Preferred filename:

```text
assets/fonts/emoji.ttf
```

Also detected:

```text
assets/fonts/emoji.otf
assets/fonts/NotoEmoji-Regular.ttf
assets/fonts/NotoColorEmoji.ttf
assets/fonts/Noto-COLRv1.ttf
assets/fonts/TwemojiMozilla.ttf
```

You can override the path at runtime with:

```bash
COWORK_EMOJI_FONT=/absolute/path/to/emoji-font.ttf cargo run
```
